## 비공개 경계

프로젝트의 팀 GitHub 조직과 Notion 기록은 구현 구조·운영·QA 맥락을 교차 확인하는 데 참고했습니다. 다만 팀 저장소는 private이며, Notion에는 내부 운영 정보와 민감한 연결 정보가 포함될 수 있으므로 URL·소스·설정값을 이 공개 저장소에 복제하거나 링크하지 않습니다.

사용자 음성·영상, 모델 가중치, 런타임 환경 변수, 데이터베이스·메시지 브로커·클라우드 설정도 동일한 이유로 제외합니다. 공개 범위의 상세 원칙은 [SOURCE_SNAPSHOT.md](../SOURCE_SNAPSHOT.md)에 정리되어 있습니다.
