# 발표 평가 수치와 확인 범위

프로필과 README는 [최종 발표자료](https://ssafy-pjt-presentation-source.vercel.app/)의 뷰어 22–24번 화면(원본 슬라이드 30–32번)을 같은 기준으로 인용합니다.

| 발표자료 항목 | 비교 대상 | aivo | 비교 |
| --- | --- | --- | --- |
| 탐지 정확도 | 모델 A · 5.5% | 76% | +70.5%p |
| 발화 분석 시간 | 모델 B · 41.5초 | 4.3초 | 약 9.6배 빠름 |

두 행의 비교 대상 모델은 서로 다릅니다. 모델 A·B는 발표자료의 익명 표기이며, 현재 공개 근거만으로 특정 모델명·버전에 대응시키지 않습니다. 기존 프로필에 있던 `whisper-1`·LoRA 모델명은 이 원칙에 맞춰 A·B로 통일했습니다.

## 확인한 것과 남은 것

| 항목 | 공개 근거로 설명할 수 있는 범위 |
| --- | --- |
| 평가 대상 | 박민규가 직접 라벨링한 발표 자료를 이용한 탐지·발화 분석 평가 |
| 지표명 | 발표자료의 ‘탐지 정확도’와 ‘발화 분석 시간’ 표기를 그대로 사용 |
| 표본 수·구성 | 현재 공개 자료에는 평가 음성 수·총 길이·화자 구성의 명세가 없음 |
| 계산 기준 | 탐지 매칭 허용 오차, TP·FP·FN, 집계 단위가 공개돼 있지 않아 accuracy·precision·recall·F1 중 하나로 재정의하지 않음 |
| 시간 측정 조건 | 해당 비교의 동일 하드웨어·캐시 상태·반복 횟수·시작/종료 지점을 확인할 공개 실행 로그가 없음 |
| 재현 여부 | 이번 문서 정리는 과거 실험을 다시 실행하거나 성능을 새로 측정한 결과가 아님 |

별도 포트폴리오 기록에는 모델명과 F1 해석이 있으나, 해당 해석을 검증할 원시 라벨·평가 코드·실행 로그가 이 공개 저장소에 함께 제공되지는 않습니다. 원래 실험 기록을 확보하면 모델 ID·버전, 표본 명세, 계산식과 실행 조건을 함께 보완해야 합니다.

## 별도 검증 기록과 구분

- README의 RTX 4050 GPU 스모크 결과인 전사 시간 **8.731초**, RTF **0.0751**은 위 발표 평가와 다른 실행입니다.
- [Coaching tests](https://github.com/scnelMG/aivo-portfolio/actions/workflows/coaching-tests.yml)는 합성 입력을 이용한 공개 음성 로직의 회귀 검사입니다. 실제 음성 탐지 성능을 다시 측정하지 않습니다.
- 이 수치로 모든 한국어 음성이나 다른 실행 환경에서의 정확도·처리 시간을 보장하지 않습니다.
