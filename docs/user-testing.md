# 외부 유저 테스트

## 검증 맥락

aivo는 SSAFY 공통 프로젝트 유저 테스트 프로그램에 선정되어, 삼성 경력사원 임직원이 서비스를 체험하고 작성한 피드백 리포트를 받았습니다. 이 문서는 포트폴리오에서 확인할 수 있는 피드백 흐름과 개선 기회를 요약합니다.

## 피드백 분포

| 우선순위 | 건수 | 의미 |
| --- | ---: | --- |
| Major | 10건 | 사용 흐름, 분석 결과 해석, 리포트 신뢰에 직접 영향을 줄 수 있어 우선 검토가 필요한 항목 |
| Minor | 7건 | 탐색성·표현·개인 설정을 개선해 사용 경험을 높일 수 있는 항목 |
| 합계 | 17건 | 유저 테스트 리포트에 기록된 전체 피드백 |

## 확인된 개선 기회

### 1. UI·접근성

연습 기록 삭제, 면접관 탐색, 슬라이드 확대, 말하기 속도·자세 수치의 해석, 녹화 전 카메라 가이드, 화면 개인 설정처럼 사용자가 화면 상태와 조작 방법을 즉시 이해할 수 있어야 하는 지점이 확인되었습니다.

### 2. 리포트 탐색·동기화

상세 리포트에서 영상·자막·슬라이드의 동기화 안정성, 그리고 진행바에서 슬라이드 전환·핵심 피드백 구간을 찾는 경험이 중요하게 제기되었습니다. 분석 결과의 정확성만큼 사용자가 결과 근거를 재생 구간에서 확인할 수 있는지도 신뢰에 영향을 준다는 피드백입니다.

### 3. AI 피드백 해석·개인화

면접 질문의 유형·난이도 선택, TTS 자연스러움, 몸짓 하이라이트와 실제 동작의 일치, 신입·경력에 따른 질문·평가 기준, 생성 질문의 사전 편집이 주요 항목이었습니다. AI가 값을 내는 것에서 끝나지 않고, 사용자가 목적에 맞게 조정하고 결과를 납득할 수 있어야 한다는 요구로 해석했습니다.

### 4. 업로드·준비 흐름

발표 자료 업로드 영역의 가시성, 업로드·변환·분석 준비 단계의 상태 안내, 면접 직군·직무 선택지 범위가 개선 기회로 확인되었습니다. 비동기 처리의 진행 상태를 사용자 언어로 드러내는 일과 입력 선택지의 범위가 완주 경험에 영향을 줍니다.
